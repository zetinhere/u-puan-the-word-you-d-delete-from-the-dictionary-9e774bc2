The one word I'd erase from the dictionary forever: **gobbledygook**.

It is the word for nonsense, and it sounds like nonsense — gobble-dee-gook,
a turkey gargling bureaucracy. Erase it and the bureaucrats have no name left
for their own language. `main.py` scores 25 candidate words against the
judge's five criteria in order (real word, funny at first sight, humour from
the word itself, freshness, exactness) and writes the winner to
`/output/entry.txt`.

## Run it

```sh
python3 main.py
```
